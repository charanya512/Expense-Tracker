# Expense Tracker Application

## About the Project
Expense Tracker is a web-based application developed using Python and Flask to help users record, manage, and organize their personal expenses. The application uses SQLite for database management.

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript (if used in the project)

## Features
- Add and manage expense records
- View saved expenses
- Update and delete expense records (if implemented)
- Store expense data using SQLite
- User-friendly web interface

## Installation and Setup

### 1. Clone the Repository
```bash
git clone https://github.com/charanya512/Expense-Tracker.git
cd Expense-Tracker
```

### 2. Install Dependencies
```bash
pip install -r requirements.txt
```

### 3. Run the Application
```bash
python app.py
```

### 4. Open the Application
Open the local URL displayed in the terminal in your web browser.
